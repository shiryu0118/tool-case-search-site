# Render.com 無料プランでのデプロイガイド

このドキュメントでは、Render.com の無料プランでツール活用事例検索サイトをデプロイする方法と制限事項について説明します。

## 無料プランの制限事項

### 1. 永続ディスクなし
- 無料プランでは永続ディスクが使用できません
- データベースは `/tmp` ディレクトリに保存され、サービス再起動時にリセットされます
- 検索履歴は一時的なものとなります

### 2. スリープ機能
- 15分間アクセスがないとサービスがスリープ状態になります
- 次回アクセス時に起動まで数十秒かかる場合があります

### 3. 月間制限
- 月間750時間の稼働時間制限があります
- 超過すると月末まで利用できなくなります

## デプロイ手順（無料プラン）

### 1. Blueprint デプロイ

1. [Render Dashboard](https://dashboard.render.com/) にログイン
2. 「New +」→「Blueprint」を選択
3. GitHubリポジトリを接続
4. `render.yaml` ファイルを確認
5. 「Apply Blueprint」をクリック

### 2. 環境変数の設定

デプロイ後、サービスの「Environment」タブで以下を確認：

#### 自動設定される環境変数
- `FLASK_DEBUG`: false
- `LOG_LEVEL`: INFO
- `CACHE_EXPIRE_HOURS`: 1
- `DATABASE_PATH`: /tmp/app.db
- `SECRET_KEY`: 自動生成
- `SHEET_NAME`: Sheet1

#### 手動設定が必要な環境変数（オプション）
Google Sheets連携を使用する場合のみ：
- `GSHEET_ID`: Google スプレッドシートのID
- `CREDENTIALS_JSON_CONTENT`: Google サービスアカウントのJSON認証情報

### 3. デプロイの確認

1. 「Overview」タブでデプロイ状況を確認
2. 提供されたURLでアプリケーションにアクセス
3. 検索機能が正常に動作することを確認

## 無料プランでの運用上の注意点

### データの永続化について

無料プランではデータベースが永続化されないため：

1. **検索履歴の消失**
   - サービス再起動時に検索履歴が消失します
   - これは正常な動作です

2. **Google Sheets連携の活用**
   - 重要なデータを保持したい場合は、Google Sheets連携を設定してください
   - Google Sheetsにデータが保存されるため、サービス再起動後も参照可能です

### パフォーマンスの最適化

1. **キャッシュの活用**
   - 外部API呼び出しのキャッシュが有効になっています
   - 同じ検索クエリの場合、キャッシュから結果を返します

2. **ワーカー数の調整**
   - 無料プランのリソース制限に合わせて、ワーカー数を2に設定しています

## Google Sheets連携の設定（推奨）

無料プランでデータを永続化するには、Google Sheets連携を設定することを強く推奨します：

### 1. Google Cloud Console での設定

1. [Google Cloud Console](https://console.cloud.google.com/) にアクセス
2. 新しいプロジェクトを作成
3. Google Sheets API を有効化
4. サービスアカウントを作成
5. サービスアカウントキー（JSON）をダウンロード

### 2. Google スプレッドシートの準備

1. 新しいGoogle スプレッドシートを作成
2. サービスアカウントのメールアドレスに編集権限を付与
3. スプレッドシートのIDをコピー（URLから取得）

### 3. Render.com での環境変数設定

1. サービスの「Environment」タブに移動
2. 以下の環境変数を追加：
   - `GSHEET_ID`: スプレッドシートのID
   - `CREDENTIALS_JSON_CONTENT`: サービスアカウントキーのJSON内容

## トラブルシューティング

### よくある問題

1. **アプリケーションが起動しない**
   - 「Logs」タブでエラーメッセージを確認
   - 環境変数が正しく設定されているか確認

2. **検索結果が表示されない**
   - 外部APIへのアクセスが制限されている可能性
   - しばらく時間をおいて再試行

3. **Google Sheets連携が動作しない**
   - `CREDENTIALS_JSON_CONTENT` の設定を確認
   - スプレッドシートの共有設定を確認

### 有料プランへのアップグレード

より安定した運用を希望する場合は、Render.com の有料プランへのアップグレードを検討してください：

- 永続ディスクの使用が可能
- スリープ機能なし
- より多くのリソース
- 24/7稼働

## まとめ

無料プランでも基本的な検索機能は利用できますが、データの永続化には制限があります。Google Sheets連携を設定することで、この制限を部分的に回避できます。

本格的な運用を行う場合は、有料プランへのアップグレードを検討することをお勧めします。
